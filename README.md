# C-like-Custom-Compiler-Greek-
This project was part of the Translators undergraduate course in the CSE Department at UoI. Main task was to develop a complete compiler for "Greek++" (a custom C-based language), covering lexical analysis, parsing, Intermediate Representation (IR) generation, and target machine code generation (Assembly).

To execute type:
python3 Greekpp_compiler.py <File.gr>
